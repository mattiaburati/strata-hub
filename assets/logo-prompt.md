# Strata Hub logo

Generated with the built-in image generation tool in generate mode. Original PNG retains transparency; the ICO exports sizes 16, 24, 32, 40, 48, 64, 128 and 256 using `scripts/Export-LogoIcon.ps1`. The executable embeds only the small ICO resource and uses native shared Win32 icons.

## Final prompt

Use case: logo-brand. Create the final standalone app icon for Strata Hub, a lightweight native local AI model manager. A distinctive bold abstract S built from three interlocking horizontal geological strata, subtly suggesting a central hub. Flat crisp vector-like geometry, elegant negative space, balanced compact silhouette, confident professional open source developer tool branding. Mint-lime green matching the app's existing mint accent, with restrained dark teal secondary surfaces only if needed. Transparent background with real alpha. One centered symbol, large within the square with 10 percent clear margin, no text, no letters as typography, no wordmark, no mockup, no shadow, no glow, no texture, no gradients, no tiny details. Must remain legible as a Windows tray icon at 16 pixels and on a charcoal sidebar.
