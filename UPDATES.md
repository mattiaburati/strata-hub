Strata Hub checks source releases and engines separately. The Updates page shows the installed standard (Qwen) engine and the latest engine offered for this PC by Strata's signed stable feed. Source versions appear in the status message; an app release such as 0.2.2 is never compared with an engine version such as 0.1.47. DeepSeek's separate package is updated through the official Strata tools, outside this Hub update button.

Installation requires a stopped model and a clean checkout with the official origin. A newer source release is fetched by tag and fast-forwarded with a backup branch. Its Python dependencies use official setup's dependency selection. Engines use the installed official signature, package hash, hardware selection and component updater. The selected engine version is checked again before installation. A binary-only test checks DLL loading and version without loading a model.

The verified package is also installed into the existing `engine` directory used by Hub profiles. The component cache being current does not imply that this executable is current. An identical installed executable is retained, including its existing rollback copy. Engine and profile backups, protected-profile hash checks and model-weight metadata checks remain enabled. Failures are shown in `strata-update.log`; Hub adds no retries or automatic rollback. Python packages are not included in the manual backup.

The header's Prefill indicator displays the engine's mean prompt-reading throughput in tokens per second, refreshed by the existing one-second metrics poll. It updates when the engine reports prompt chunk progress. Missing data, a sample older than three seconds, a stopped server or a phase other than prompt reading displays N/A. Prefix reuse is accounted for by the engine; Hub does not divide the entire prompt by wall-clock time. Generation Live, Mean and Last request rates remain separate.

Focused checks: `python -m unittest discover -s tests -p test_updates.py` and `cargo test --locked --offline prefill_rate_`. Build with the existing release toolchain and static CRT settings.
